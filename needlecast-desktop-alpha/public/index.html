FIRST-RUN SETUP / CONFIGURATION

Connect your setup

Credentials are encrypted locally using Windows secure storage. Needlecast never sends them to a Needlecast server.

Discord voice bot

Create a bot in the Discord Developer Portal. Grant only View Channels, Connect and Speak permissions for your server. Never commit its token to GitHub.

Discogs collection · optional

Optional. You can leave both fields blank and use a local CSV import or manual album entry. A token enables collection sync.

Discord presence

Discord does not support cover images inside a bot’s Listening activity. This option changes the bot’s profile avatar while an album is selected, then restores its original avatar when Now Playing is cleared. Discord may rate-limit avatar changes.

Restart required after saving credentials.
